### 3. What is a Commercial License?
A Commercial License is a **separate, proprietary licensing agreement** designed for companies and organizations that cannot or do not wish to comply with the copyleft obligations of the AGPL-3.0.

Under a Commercial License, licensees can:
* Embed and link the Software or its computational engine into proprietary, closed-source products,
* Keep proprietary modifications, optimizations, and internal engineering intellectual property confidential,
* Deploy the Software as a hosted web tool or SaaS solution without disclosing server-side source code to network users.

### 4. Who Requires a Commercial License?
A Commercial License is required if you plan to:
* **Embed in Closed-Source Products:** Distribute the Software or components of it as an integrated part of a proprietary software application, hardware appliance, or commercial suite without making the source code available.
* **Provide SaaS / Network Services Without AGPL Source Sharing:** Host the Software or modified versions on private servers to deliver network services or calculation APIs to external customers without providing complete source code download access.
* **Distribute Proprietary Modifications:** Ship customized binaries to third parties while keeping internal modifications, algorithms, or competitive features private.
* **Corporate Policy Compliance:** Satisfy internal security, intellectual property, defense, or aviation procurement policies that explicitly disallow copyleft or AGPL licenses in internal and client-facing technology stacks.

A Commercial License is **not required** for:
* **Hobby & Personal Use:** Building and calculating model aircraft or personal UAS designs.
* **Academic & Scientific Research:** Non-commercial educational, thesis, and laboratory research.
* **Internal Utilization:** Utilizing the Software strictly as an in-house design tool without distributing it or offering it as an external network service.
