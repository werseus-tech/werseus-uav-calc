# WerSeuS – UAV Calc v0.0.1

## English

A free, open-source Windows desktop tool for the preliminary design and analysis of small electric UAVs: fixed-wing (conventional, V-tail, flying wing), multirotor and VTOL quadplane. Built for students and hobbyists; available in Turkish and English.

### Highlights
- Guided step-by-step design wizard, with a free Expert Mode once all steps are valid, and a Simple mode for beginners.
- Three-panel interface with light/dark theme, live analysis results, scaled 2D drawings and a CAD-style 3D view.
- Aerodynamics, propulsion, endurance, stability and structure calculations for all supported platform types.
- Teacher mode: per-step lessons, mini quizzes, "why this result?" explanations and a class report.
- Optional AI assistant (local Ollama or cloud providers). Off by default; it only proposes changes, and you approve and can undo them.
- Wind tunnel at preliminary-design level: 2D panel method with boundary layer and a 3D vortex lattice method.
- Optional FreeCAD export: parametric parts, assembly (`.FCStd` / `.STEP`), bill of materials and interference check.
- Excel export, Markdown design report, and a community component database (motors, propellers, ESCs, cells, packs).

### Download & run
1. Download `WerSeuS-UAV-Calc-v0.0.1-windows-x64.zip` from the assets below.
2. Extract it to a folder.
3. Run `werseus-uav-calc.exe`. No installation is needed.

### Requirements
- Windows 10 or 11, 64-bit.
- Optional: FreeCAD 1.x for CAD outputs; an AI provider (local or cloud) for the AI assistant.

### Windows SmartScreen note
The executable is not code-signed, so SmartScreen may show a warning. Click **More info → Run anyway**. To verify your download, compare the hash with `SHA256SUMS.txt`:

```powershell
Get-FileHash .\WerSeuS-UAV-Calc-v0.0.1-windows-x64.zip -Algorithm SHA256
```

### Known limits
- This is a preliminary-design tool. Results are estimates and must be verified (ground tests, flight tests, a qualified expert) before any flight. See [DISCLAIMER.md](https://github.com/werseus-tech/werseus-uav-calc/blob/master/DISCLAIMER.md).
- Windows only for now.

## Türkçe

Küçük elektrikli İHA'ların (sabit kanat, V-kuyruk, uçan kanat, multirotor ve VTOL quadplane) ön tasarımı ve analizi için ücretsiz, açık kaynaklı Windows masaüstü programı. Öğrenciler ve hobiciler için geliştirildi; Türkçe ve İngilizce kullanılabilir.

### Öne çıkanlar
- Adım adım tasarım sihirbazı; tüm adımlar geçerli olunca serbest Uzman Modu, yeni başlayanlar için Basit mod.
- Açık/koyu temalı üç panelli arayüz, canlı analiz sonuçları, ölçekli 2D çizim ve CAD tarzı 3D görünüm.
- Tüm platform türleri için aerodinamik, itki sistemi, uçuş süresi, denge ve yapı hesapları.
- Öğretmen modu: adım dersleri, mini testler, "Neden bu sonuç çıktı?" açıklamaları ve sınıf raporu.
- İsteğe bağlı yapay zekâ yardımcısı (yerel Ollama veya bulut sağlayıcılar). Varsayılan olarak kapalıdır; yalnız öneri sunar, onaylayıp geri alabilirsiniz.
- Ön tasarım düzeyinde rüzgâr tüneli: sınır tabakalı 2D panel yöntemi ve 3D girdap kafesi yöntemi.
- İsteğe bağlı FreeCAD çıktısı: parametrik parçalar, montaj (`.FCStd` / `.STEP`), malzeme listesi ve çakışma kontrolü.
- Excel dışa aktarma, Markdown tasarım raporu ve topluluk bileşen veritabanı (motor, pervane, ESC, hücre, batarya paketi).

### İndir ve çalıştır
1. Aşağıdaki dosyalardan `WerSeuS-UAV-Calc-v0.0.1-windows-x64.zip` dosyasını indirin.
2. Bir klasöre çıkarın.
3. `werseus-uav-calc.exe` dosyasını çalıştırın. Kurulum gerekmez.

### Gereksinimler
- Windows 10 veya 11, 64 bit.
- İsteğe bağlı: CAD çıktıları için FreeCAD 1.x; yapay zekâ yardımcısı için bir sağlayıcı (yerel veya bulut).
