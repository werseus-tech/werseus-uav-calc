# Güvenlik Politikası / Security Policy

## Desteklenen Sürümler (Supported Versions)

Aşağıdaki sürümler için güvenlik güncellemeleri yayınlanmaktadır:

| Sürüm | Destekleniyor mu? |
|---|---|
| `0.1.x` | Evet |
| `< 0.1.0` | Hayır |

## Güvenlik Açığı Bildirimi (Reporting a Vulnerability)

"WerSeuS – UAV Calc" uygulamasında tespit ettiğiniz potansiyel güvenlik açıklarını lütfen **genel GitHub Issue alanında paylaşmayın**.

Güvenlik açıklarını doğrudan proje geliştiricisine iletin:

- **E-posta**: `info.wsseng@gmail.com`
- **Konu Başlığı**: `[GÜVENLİK / VULNERABILITY] WerSeuS UAV Calc`
- **İçerik**:
  - Açığın kısa tanımı ve etkilediği bileşen.
  - Açığı yeniden oluşturma adımları (PoC).
  - Varsa çözüm veya yama öneriniz.

Bildiriminiz 48 saat içinde incelenecek ve düzeltme hazır olana kadar sorumlu açıklama (responsible disclosure) ilkeleri çerçevesinde gizli tutulacaktır.
